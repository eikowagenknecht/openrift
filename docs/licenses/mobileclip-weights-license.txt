The scanner's encoder derives from MobileCLIP-S0 v1 weights released by Apple
in 2024 under the license above (apple/ml-mobileclip, file
LICENSE_weights_data as of commit 341ef058802f0e4e5ab13c02f0cb32a3a94e367b),
which permits use, reproduction, modification and redistribution in source or
binary form without field-of-use restriction. The ONNX export used as the
conversion source is Xenova/mobileclip_s0 (created 2024-04-24). In August
2025 Apple replaced the license for NEW distributions of this repository with
the research-only "Apple Machine Learning Research Model" terms; do not
re-download weights from the current repository — the archived copies and the
fp16 conversion in data/image-recognition-test/models/ trace to the 2024
terms. Serve this file next to the encoder (media/scan/) per the runbook.
